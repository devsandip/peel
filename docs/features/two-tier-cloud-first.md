## Confirmed product decision

| Tier                                                   | Authority and storage                                                                                  | Cross-device behavior                                                                                                                                                                               |
| ------------------------------------------------------ | ------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Local storage (free)                                   | Each installation's own durable local library                                                          | None. Laptop, phone and browser libraries are independent. No discovery, device list, pairing, signaling, relay, periodic peer sync or awareness of another installation.                           |
| Cloud storage (paid, commercial terms still undecided) | One authenticated whole-library DynamoDB authority, with account-bound local caches and pending drafts | Commit to Cloud first, then push committed changes to online clients. The complete committed library is available from the authenticated web interface even when the originating device is offline. |

Sandip chose offline pending drafts rather than disabling offline edits. A device may durably retain an unconfirmed draft locally for crash recovery, upload it on reconnect and preserve it through authentication/conflict failures. That draft is not yet a canonical Cloud save and cannot appear on other devices/web until its source uploads successfully. In the Cloud tier, show Saved only after the server confirms the matching current edit. A local cache/draft commit, sent request or push notification is insufficient. Pending newer typing remains pending even if an older operation is acknowledged. Local storage continues to show Saved on this device after its local commit.

Cloud Put away may close after durable pending-draft retention without a network round trip, but must keep Pending upload visible in the library and never label the edit Saved. Failed local retention keeps the editor open. Keep server conditional revisions and explicit preservation/resolution of concurrent offline Cloud drafts; do not introduce peer clocks or a silent last-writer overwrite. Server-confirmed notes remain readable from caches offline; Cloud authentication/entitlement governs server access and account boundaries remain intact.
