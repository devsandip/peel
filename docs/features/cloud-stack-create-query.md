## Purpose and limits

Add `checkCloudStackCreateQuery(handle, view)` beside the private original-request material. This pure consistency check requires the genuine still-active request handle. A recovered projection, JSON/copy or discarded handle cannot supply material. It compares all unsigned Query fields with that exact original input, including its transient NoEcho parameter, without creating another key/token or recomputing current templates. It does not consume the handle or authorize any provider request.

The closed view contains method, protocol, hostname, explicit port (`null` for omitted or443), path, empty query object and a string body. A future trusted adapter must capture those fields from the actual outgoing request without getters; the caller view alone proves no transport provenance. Require POST, HTTPS, the fixed CloudFormation us-east-1 host and root path. Bound the ASCII form body to256KiB, strictly decode percent escapes/UTF-8 and reject duplicate, unknown, missing or altered fields. Require Action=CreateStack and Version=2010-05-15. Compare exact template/parameter/token/tag/capability/timeout/rollback/deployment/termination and all omission semantics; never discard an unknown service field or coerce a value. Form order and equivalent legal percent encodings may differ. An omitted default is not equivalent to the original explicitly supplied value. Empty lists/objects and indexed list gaps/extras are not silently normalized away.

Derive expected Query names from the already validated, detached private input, using the service's explicit dot/member encoding. The original full unsigned commitment already binds that input, its original context/intent and destination. Return only a detached frozen metadata projection with the original request/full unsigned pins, stack kind, body byte/field counts, unsigned consistency, unproven ownership/run/current/transport authority and zero resource writes. Do not retain or echo the body, headers, raw template/parameter, NoEcho value, credentials or a separate secret hash. Private failures have one fixed message and no cause/details. Existing request APIs/projections/goldens stay compatible.

Headers/signature/account identity, actual current collectors/private assessments, adequate phase runway, durable winning preparation, acknowledged one-use fence, real bounded transport, provider response/ownership/settlement and cleanup remain separate disabled work. This checker never exports an SDK runner/HTTP transport or turns a body match into a send capability. A pure handle also supplies no trusted coordinator session. No filesystem/SQL/network/RNG/current factory/default clock is needed by the checker.
