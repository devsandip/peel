# Original stack creation-intent identity

## Purpose and boundary

[Issue102](https://github.com/devsandip/peel/issues/102), under issue30/[M2.2](https://github.com/devsandip/peel/milestone/2), defines one pure non-executable identity codec after [bound context persistence](cloud-run-context-storage.md). It supports SPEC FR-04/14/20 and AC-04/12/13 prerequisites with [original context](cloud-run-plan-context.md), [recipe](cloud-run-manifest.md), [historical inventory](cloud-historical-inventory.md) and [hosting](cloud-dev-hosting.md). Canonical v0.7 and existing formats stay unchanged. Durable token storage, full wire request/parameters/roles, provider provenance, phase/execution/current safety and lifecycle remain separate work.

## Identity contract

Require exact original context JSON/independent context SHA and original recipe JSON/pins. Use original codecs/catalog and retained canonical five-template bundle only; no current factories/name helpers/validator/cost/clock. Select artifacts->artifact-bootstrap, guard->cleanup-guard, sentinel->cleanup-sentinel, data->private-hosting. Retain the SHA of the exact canonical selected original template object; this does not validate a complete executable request or prove that resources belong to the run.

The bounded4KiB format1 identity binds original context/manifest/normalized-plan/inventory digests, profile/account/region/run, stack kind/original name/template digest and original client request token. Strict root/nested schemas, canonical JSON and an independently expected descriptor SHA/pin reject changed bytes and semantic mismatches. Return detached frozen identity/bytes/pins with ownership/run authority unproven and resourceWrites0. Pins are integrity expectations, not provenance or permission. A valid different nonce with new independent pins is a different descriptor; only later durable uniqueness/execution code can prevent another submission.

Peel's v1 token policy is peel-<original-run-UUID>-<stack-kind>-<lowercase-v4-UUID-nonce>. The codec accepts it explicitly and retains it; it generates no token or randomness and proves no entropy/provider acceptance. AWS [CreateStack](https://docs.aws.amazon.com/AWSCloudFormation/latest/APIReference/API_CreateStack.html), rechecked28October2026, documents retry/event correlation,1..128characters and an alphanumeric first character followed by alphanumeric/hyphens. AlreadyExists/TokenAlreadyExists are errors, not successful creation, complete absence or ownership. Peel's narrower encoding is our policy, not an indefinite exactly-once guarantee. No CLI/API request or retry belongs in this slice.
