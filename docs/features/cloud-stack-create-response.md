# Bounded original CreateStack response observations

[Issue 137](https://github.com/devsandip/peel/issues/137) is one supplied-data integrity prerequisite under issue 30 / [M2.2](https://github.com/devsandip/peel/milestone/2), supporting [SPEC](../SPEC.md) FR-04/14/20 and AC-04/12/13. Read the [creation journal](cloud-creation-journal.md), [original request](cloud-stack-create-request.md), [unsigned Query](cloud-stack-create-query.md) and [phase/provenance](cloud-reserved-phase-gates.md) contracts. This plan precedes fixture generation/code. Functional v0.7 and existing stores/schemas remain unchanged.

## One purpose

Add pure create/read codecs in `infra/cloud/stack-create-response.ts` for a bounded whitelisted observation of supplied SDK success identifiers. The observation binds an independently pinned original request projection/context/intent through the existing reader. It does not establish that any request was sent or acknowledged, that a response actually came from AWS, or that the named operation/resources are owned or settled. A future trusted response adapter and journal writer must retain actual dispatch/source/provider provenance separately. Recovery can read integrity-checked observations but cannot continue creation.

Factory input is a closed record with `request` (original projection JSON and its existing expected original/intent/pin), `observedAt` and `response`. SDK response permits only required StackId/$metadata and optional OperationId; metadata permits only httpStatusCode/requestId/extendedRequestId/cfId/attempts/totalRetryDelay. Known optional OperationId and extendedRequestId/cfId may be absent or explicit undefined, as SDK objects can represent omission that way. Other undefined/null/coercion/unknown fields refuse. Require HTTP200, attempts1, totalRetryDelay0 and a nonempty requestId. Extended/cf metadata must remain absent/undefined. Do not accept error objects, AlreadyExists/TokenAlreadyExists, raw event properties/parameters or status reasons as success observations.

StackId must be the canonical `arn:aws:cloudformation:<original-region>:<original-account>:stack/<original-name>/<lowercase-UUID>` under the existing reviewed stack-metadata policy (any UUID version, not an assumed v4). OperationId is optional and normalized to null. For both requestId and present OperationId, v1 conservatively supports1..128 ASCII characters, an alphanumeric first character and subsequent alphanumerics/underscore/dot/colon/hyphen. This is our bounded identifier policy, not an AWS UUID/length guarantee; unsupported identifiers refuse without echoing them. The [AWS CreateStack API](https://docs.aws.amazon.com/AWSCloudFormation/latest/APIReference/API_CreateStack.html), rechecked29October2026, documents StackId and OperationId as unique string identifiers, without guaranteeing an OperationId UUID shape. A returned ID is not independent ownership proof.

ObservedAt is exact canonical millisecond UTC text no earlier than the original lease start. It is supplied data, not authenticated wall time. Preserve late replies after readiness/test/cleanup deadlines for inspection; recording a late observation never extends a lease or enables progress. No default clock, current validator/name/template factory, RNG, filesystem/SQL/network, credentials or actual provider data collection.

## Canonical format and reader

Canonical JSON is at most2KiB with fields in this order: format1; kind `synkies-cloud-stack-create-response`; original runId; stackKind; original requestSha256 and unsignedSha256; observedAt; stackId; nullable operationId; requestId; httpStatusCode200; attempts1; totalRetryDelay0; providerObservation/ownership/operationSettlement/runAuthority all `unproven`; resourceWrites0. The latter describes writes by this codec, not whether the supplied original request had provider side effects. Retain no raw response, headers, status reasons, role/session ARN, template/parameter/NoEcho value, credentials or separate secret digest. These are approved bounded identifier/count projections for a future private operator journal, not public account reports.

Return detached frozen JSON, SHA and observation. Reader input includes the exact original request expectation and independent expected observation SHA. Validate all original bindings/identifier/time/constant flags again, require exact canonical bytes and SHA, reject extra/getter/prototype/encoding/size errors privately, and return the same unproven metadata. No active handle, readiness brand, row write or capability is restored. An attacker can construct coherent supplied data; integrity is not authenticated provenance. No journal schema/row/API change belongs here.
