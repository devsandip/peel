## Implementation and validation

The reusable browser sender captures the trusted origin and issued-CSRF-shaped material. It accepts only fixed bootstrap/page/checkpoint requests, uses same-origin credentials/mode, no-store, redirect refusal and no referrer. One10s deadline covers headers and the entire body, including an injected fetch that ignores cancellation. A fixed640KiB buffer bounds the decoded response; strict content type/UTF8/JSON and declared/streamed byte checks reject invalid responses. Cancellation closes/releases readers, clears timers/listeners and cancels late abandoned responses. Source review replaced a per-chunk abort race with one whole-body race so abort handlers stay bounded. This sender neither issues a session nor grants paid access.
